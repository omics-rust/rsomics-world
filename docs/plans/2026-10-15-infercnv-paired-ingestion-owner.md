> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** Run the already implemented real factories in the exact32-slot
schedule, authenticate their inputs/code/runtime, and retain a complete
auditable result even when a process or postcheck fails.

**Architecture:** One private stdlib controller composes the accepted process
owner, closed metadata checker and exact campaign checker. The workflow owns
network acquisition, dependency installation, package contracts and native
compilation; this owner is offline and never builds or installs. A later

**Tech Stack:** Python3.12 stdlib, existing actual R4.6.1/infercnv1.28 factories,
the frozen four-native-tested private Rust bench and GNU time on Linuxx86_64.
