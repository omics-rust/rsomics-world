T1/T2/C1/C2,100k treatment and60k control molecules per sample. Treatments have
400 separated enrichment loci plus diffuse background; PE75M reads have
180-260bp fragments, with physically separate balanced-strand SE projections.
One molecule ledger determines pairs/SE identity, coordinates and truth.
Add a small valid named flag/MAPQ/split/spanning-pair panel, not malformed
records disguised as biology. Preserve sorted/indexed BAM validity, dictionary,
pair/TLEN counts, exact program/version/seed, all hashes and actual sizes.

silently. Generation can run hosted before source calls, with its frozen
generator and complete input manifest retained before any oracle execution.

rows include duplicate display IDs/coordinates, exact duplicate rows with

SE/model+pooled control, pooled SE/explicit length/no control, pooled PE/control
and pooled PE/no control. Cover duplicate1/auto/all, p/q and track outputs

Bioc3.23 and every installed package/source hash; bedtools binary/compiler/
compression libraries; shell tools and thread settings. Reuse existing pinned
hosted acquisition/storage/manifest helpers where contracts match. Runtime
objects are retained inside an archive, not a lossy case-folded upload tree.
No local scientific imports, R install/build, upstream execution or benchmark.

Retain exact argv/env/cwd, process status/stdout/stderr, executable/source/input/
output hashes and sizes, machine/runtime identity and all partial failures.
Capture exposed MACS state/logs. Optional instrumented diagnostic projections
must be separately labeled and match unmodified final output; they are not
required public APIs or performance evidence. SEACR intermediate retention
must not change original source behavior; do not admit differing diagnostics.
Same-profile fresh-process TxDb/csAnno and retained R-state reloads verify
exports without silently rebuilding/refitting. No cross-version S4/RDS claim.

concentrated fix wave precede hosted dispatch. Source oracle capture can be
one real Linux host; later PRODUCT native compatibility must exercise all four
classes. Do not require installing every upstream stack natively on all four
as an additional gate. The old ChIPseeker1.46.1 two-profile reconstruction is
deferred provenance research, not a prerequisite for the current workflow.
