## Initial actual workflow witness

1. Build a small valid BAM/BED12 family using installed pysam on the hosted
   runner. Include expressed plus/minus transcripts, exon/intron/boundary
   reads, paired and unpaired records, mapping/QC/duplicate/secondary flags,
   splices, soft clips, insertions/deletions and =/X CIGAR. Include a
   transcript with concentrated positive coverage/entropy zero and an
   eligible zero-coverage transcript so the known TIN donor bugs are visible.
   Use separate named profiles only where a mixed fixture obscures the
   declared source population. Preserve SAM/BAM/BAI/BED12 and manifest.
   Actual source requires separate single/paired profiles: mixed usable reads
   produce "Mixture" with no strandedness fractions despite exit0. TIN needs
   more than10 distinct starts;11 intronic starts make the zero-exon-coverage
   transcript genuinely eligible rather than merely empty. The positive
   entropy-zero case has one sampled exonic base plus11 intronic starts.
2. Execute all five actual scripts with declared complete argv and capture
   stdout/stderr/status/generated numeric tables. Keep R-script/plot outputs
   separate from numeric evidence. Use a sufficient valid transcript length
   and read count for actual default eligibility, not an empty "success".
   All five outcomes are retained even if one fails; the witness is nonzero
   unless every declared operation produces its expected numerical output.
   geneBody_coverage uses its supported --skip-plot; no R install is needed.
3. Preserve exact machine/tool/dependency/input/code hashes and source
   original files. A package failure is evidence to diagnose, not permission
   to invent a passing expected table or silently switch an upstream version.
4. Root inspects actual outputs and reconciles the known distribution/CIGAR,
   coverage/pileup and TIN disagreements before migrating the shared engine.
   Canonical complete CIGAR remains distinct from any explicitly selected
   legacy profile. This fixture establishes bounded functional behavior,
   not representative speed or RNA-seq biological validity.
