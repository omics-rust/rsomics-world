### Model and planning boundary

`ChromId(u32)` is an index into `ChromDictionary { entries: Vec<Chromosome> }`, with `Chromosome { name: String, len: u32 }`; duplicate names, zero/impossible lengths and coordinate conversion failures error on input. `Span { chrom: ChromId, start: u32, end: u32 }` is nonempty half-open. Window planning uses signed i64 offsets before one checked clip, so upstream out-of-range matrix padding never underflows.

`Sample { path: PathBuf, label: String }`; `SampleId(usize)` and `GroupId(usize)` preserve input order. `Region { row_id: u64, chrom: String, exons: Vec<Range<u32>>, name: String, strand: Strand, score: String, group: GroupId, source_order: u64 }`; exons are ordered checked blocks; preserve exact region identity and score representation required by source serialization. `RegionSet { regions, group_labels }` can retain chromosome strings absent from a signal dictionary for counted missing rows.

`SignalRun { span: Span, value: f64 }` stores actual values, including legitimate IEEE nonfinite states. No run means missing; an explicit 0.0 run is data. `NumericClass` is only for diagnostic export (`finite`, `nan`, `pos_inf`, `neg_inf`), not an arithmetic wrapper or blanket finite filter. `BinValues { task: TaskId, windows: Vec<Span>, values: Vec<f64> }` is one sample vector. `RowValues { row_id, values: Vec<f64> }` is row-major sample blocks, not a collection of singular matrices.

`OperationPlan` variants contain complete `TrackPlan`, `ComparePlan`, `AveragePlan`, `SummaryPlan`, `MatrixPlan`, `FilterPlan`; `validate(cli: Cli) -> Result<OperationPlan>` resolves incompatible flags, default modes, sample cardinality and output aliases before expensive work. `execute(plan: OperationPlan, context: &RunContext) -> Result<ExecutionReport>` is the only dispatch entry. `RunContext { threads: NonZeroUsize, scratch: PathBuf, max_inflight: usize }` owns worker/task scratch, not global env mutation after threads start.

### Shared planner, not a universal grid

`DictionaryProfile::{BamCount, BwArithmetic, BwSummary, MatrixLookup}` selects exact source name/length/alias policy. `reconcile(inputs: &[ChromDictionary], profile) -> Result<DictionaryMapping>` returns output dictionary and per-sample source-name mapping plus warnings. BAM intersects equal name+length pairs preserving first order and only attempts prefix correction when no exact common pair. BW arithmetic intersects names/min lengths in encounter order without prefix rewriting. BW summary uses equal pairs/prefix fallback and lexical chromosome order. Matrix uses per-region lookup including chrM/MT source rules. Keep these separate; no global alias cache.

`TaskId { chrom_order: u32, start: u32, ordinal: u64 }`; `Task { id, span, grid_origin: u32 }`; `GridProfile::{BamTrack, BamSummary, BwTrack, BwSummary, Filter}` includes the source density/chunk/step settings. `plan_tasks(dict, profile, region, mask) -> Result<Vec<Task>>` freezes semantic chunk boundaries independently of worker scheduling. Source blacklist subtraction yields surviving subranges and new grid origins. BAM summary's observed 333-base source tasks must remain 29x2 rows for the frozen fixture rather than BW's 25x2 global rows. Region/start rounding and final short bins use the source profile, not one formula everywhere.

`MaskIndex::subtract(span) -> Vec<Span>`, `contains_start(chrom,pos) -> bool`, `neighbors(span) -> Bounds`, and `normalization_population(...)` are separate private operations. Reject malformed and overlapping normalization blacklist spans as the actual source contract requires; do not merge away an invalid scaling population. A read spanning a blacklist can remain; no universal overlap rejection.

### Alignment/count/normalization seams

`FilterPolicy { mapq, include_flags, exclude_flags, fragment_bounds, dedup, rna_strand }`; `FilterState` is task-local positional duplicate state keyed by reference start and source fragment/mate/orientation tuple. Unmapped/secondary/supplementary/QC-fail handling is selected by operation, not imposed by a shared reader. `accept(record, policy, state) -> Result<FilterDecision>` distinguishes rejected and source shift-dropped populations for counters.

`CoverageModel::{AlignedBlocks, Extended(Extension), Offset(OffsetSpec), Mnase}`; `geometry(record, model, context, reusable_blocks: &mut Vec<Range<u32>>) -> Result<GeometryDecision>` handles M/=/X, D/N gaps, insertions/clips, paired predicate, fragment bounds, strand and clipping. `count_task(reader, task, model, filters) -> Result<BinValues>` increments each read/bin at most once across blocks; mates are separate unless selection masks reduce them. Use per-task integer difference runs/block hit ranges rather than dense whole-genome per-base arrays; source matrix widths and final clipping are explicit.

`NormalizationRequest::{None, Cpm, Bpm, Rpkm, Rpgc{effective_genome_size}}`; `ScaleRequest::{Manual(Vec<f64>), ReadCount, Ses{sample_length,number_of_samples}, Normalize(NormalizationRequest)}`. `estimate_population(bam, request, filters, mask) -> Result<PopulationEstimate>` records index total, ignored chromosomes, blacklist total, sampled/filtered counts, fraction, exact/scanned flags and denominator. `resolve_scales(...) -> Result<ScaleReport>` freezes factors before counting/writing. N may be fractional; do not force integer kept estimates. CPM=1e6/N, BPM preserves actual CPM-equivalent path, RPKM=1e9/(N*configured bin size), RPGC=effectiveGenome/(N*sampled-median-or-extension length); user scale multiplies. IgnoreDuplicates alone retains source denominator behavior.

SES has its own unfiltered sampler profile, deterministic sample identity/order and cumulative sorted rank algorithm; do not accidentally feed command MAPQ/dedup/extension to that sampler. Source zero-median error and prohibited normalization combinations fail loudly. Main fixture report must recover 64/124 and factors 15625/8064.516129032258, readCount 1/0.5161290322580645 and SES 1/0.5 with 24 sampled 50-base regions.

### BW, reducers and row windows

`BigWigSource::open(path) -> Result<Self>`, `dictionary()`, `full_runs(span) -> Result<RunIter>`, `zoom_runs(span, reduction) -> Result<ZoomIter>`, `mean(span, StatsMode::{Approximate356, Exact}) -> Result<f64>` form the private codec boundary. Codec errors carry path/chrom/query context. Full-value arithmetic never calls zoom means; missing-as-zero is applied per missing/NaN base before the bin average; skipNAs poisons partly missing bins instead of silently nanmeaning them.

`Arithmetic { operation, scales: [f64;2], pseudocount: [f64;2], skip_both_zero: bool }::apply([f64;2]) -> BinDecision` applies zero predicate before scales/pseudocounts, then source arithmetic order; `BinDecision::{Value(f64), Gap}`. Average uses an ordered N-input sum of scaled bin means / N. NaN, +Inf and -Inf remain distinct. Source matrix reduction masks NaN and Inf; BW arithmetic does not. `reduce(values, Reducer, MissingPolicy) -> f64` must therefore be invoked with an operation-selected policy, not an unconditional shared nanmean.

`WindowPlan { row_id, zones: Vec<Zone>, reverse: bool, bins_per_sample: usize }`, `Zone { blocks: Vec<WindowBlock>, bins: usize }`, `WindowBlock::{Genomic(Span), Missing(u32)}`. `plan_windows(region, MatrixGeometry, dictionary_mapping) -> Result<WindowPlan>` performs exon-aware TSS/TES/center/flank/body/unscaled chopping. Integer linspace floor boundaries plus at least one input base per output bin match source; no interpolation. Reversal happens per sample block after reduction, not across samples. Short/absent regions retain source counted exclusions/warnings; no region-error blanket suppression. `compute_row(sources, window, params) -> Result<RowDecision>` evaluates inclusive thresholds before scale, then skipZeros using masked/zero row mean; sorting is stable within group using requested sample subset.

## 4. Approximate summaries and native BW construction: graph contract

There are three distinct tests, all required; passing one does not substitute for another.

1. **Imported original bytes:** run native approximate and exact statistics on the original historical BWs and authored zoom BW. Compare default to the retained default exports and exact to retained exact exports. A recorded difference is mandatory: zoom track 0–20003 default 2.985 vs exact 2.9975; 17–1813 default 2.979240806642941 vs exact 3.0211581291759466. Main source A 17–1813 default 41302.48134566038 vs exact 42907.85077951002. Do not coerce equality or use a header mean as either query answer.
2. **Connected native files:** native filter -> native tracks -> native compare/average -> native BAM/BW summaries and matrix. Qualified pinned upstream reads those exact native BW files for default `stats`, exact diagnostics, `multiBigwigSummary` and computeMatrix. Native summary must agree with source on the same native BW, including selected zoom level, fractional-edge weighting, exon-length weighting and poisoned missing exons. No upstream-produced replacement BWs enter this lane.
3. **Writer semantics across equivalent values:** record native/source full runs, dictionary, zoom reductions, per-query selected zoom and zoom records/statistics. Full-value parity does not imply default summary parity. Require source-compatible approximate behavior on equivalent run streams, while allowing byte/index/compression offsets to differ. Compare corrected native output against a source-produced BW from the corrected run stream when approved data fixes change the stream; this is a comparator output, not a patched upstream or replacement graph input. A failure here is an actual private writer/stats integration task, not permission to widen numeric tolerances or switch to exact.

Retained candidate facts: bigtools0.5.8 `BigWigWrite::write` and `write_multipass` are temp-backed; `BBIWriteOptions` exposes `initial_zoom_size=160`, `max_zooms=10`, `manual_zoom_sizes`, `items_per_slot=1024`, `block_size=256`, `channel_size=100`, `inmemory=false`. Single-pass auto levels multiply initial by four; multipass uses an interval-size/data-size heuristic. These defaults are NOT evidence of libBigWig-compatible output. Accepted source first reductions are 560 for main A, 448 for original derived compare and 80 for authored zoom. Freeze a private `BbiWriteProfile::DeepTools356` which computes source-compatible levels from the actually emitted quantized run stream (including corrected tails), selects manual levels where needed and records them. Do not hardcode 560 to all tracks, disable zooms or select an exact-only writer to evade default-summary compatibility.

Qualification during implementation starts with actual bigtools0.5.8 + bamio dependency resolution/build and a small complete track/summary round trip, not a separate speculative codec audit. Determine whether candidate zoom assembly plus public controls reproduce the required profile; correct the narrow private adapter if necessary. If actual source and native evidence contradict and no bounded adapter can honor the adopted approximation contract, record the exact mismatch for the parent—no assumed impossibility now. Malformed blocks/decompression/I/O panic boundaries are tested in the same integrated checker; catch a codec unwind at the owning worker boundary only to return contextual nonzero failure and cancel publication, never treat panic as successful missing data. No new codec/public foundation is preauthorized.

## 5. Output, format, error and resource contracts

- `OutputSet::stage(paths)` composes existing common `AtomicFile` and `commit_all`, with input/output and output/output alias rejection including existing hardlinks/symlinks. Stage beside final destinations (external during this project), and use external scratch for spool/codec tempfiles. Explicit paths are required for BAM/BW/NPZ/gzip matrices; initial release does not promise transactional binary stdout. Reports are last-written staged members, not pointers to partial files. `commit_all` provides recoverable multi-file publication, not impossible crash-atomicity across filesystems.
- `RunSink::push(BinDecision)` and `finish()` carry a real `Option<PendingRun>`. Flush before gaps, task/chrom changes and EOF; compare values before output quantization; coalesce adjacent equal runs only where source operation does so. Corrected explicit zero tails stay. Fixed-step emits each source bin, final short bin and legitimate nan/inf text. Merged path omits NaN runs but preserves infinities according to source contract. No silent finite-only filtering at BW encoding.
- bedGraph uses source six-significant-digit general format; BW receives that parsed decimal rounded to float32, not unrounded f64. Parsing/serializing `nan`, `inf`, `-inf` is an explicit format contract; independent BW reader must verify candidate codec behavior on each class. Valid nonfinite outcomes may not be converted to zero. If the format/codec cannot represent a requested class, return a named serialization error before publish rather than invent an interval.
- Summary NPZ is a standard ZIP of `matrix.npy` (C-order `<f8`, shape rows x samples) and `labels.npy` (non-object NumPy Unicode array, exact labels). No Python/pickle dependency. Write source-compatible raw-count headers/row coordinate lists, literal nan/inf representation and optional BAM scaling factors from the same row population. TSV and NPZ are staged together. Row metadata/report records stable row IDs even though NPZ only contains matrix/labels.
- Matrix gzip begins with `@` plus compact JSON and LF; required source keys, per-sample special-parameter arrays, sample/group labels/boundaries and rows are preserved. Each row has six BED-ish fields followed by six-decimal cells; exon starts/ends are comma lists. Optional matrix TSV and sorted BED derive from identical row/sort decisions. Gzip timestamp/compression bytes and JSON object order are not compatibility predicates; parsed schema/rows are.
- Filter unshifted kept/rejected records retain original payload semantics, sequence/quality/tags, header dictionary and required header updates. Shift creates source-compatible match-only records with no sequence/qualities/aux, changed start/CIGAR/TLEN/mate starts, checked through bamio encoding rather than manual byte splice. Excluded output always original rejected BAM. Shift-dropped proper-pair/geometry failures are counted separately in report and preserve source metrics convention rather than being added to nFiltered. MACS fragments use positive signed TLEN, left position and clipped right end; not BEDPE or insertion sites.
- No hidden sort/index. BAM filter output is deterministically source-task ordered; retain the source header/metadata profile, report separately the measured coordinate-order status and warn when a shift invalidates it, and state that downstream indexed consumers require explicit sort/index. Source fixture happens to remain ordered; test adversarial shifts too. A copied header sort declaration is not evidence of sorted records. Do not add an unapproved fourth metadata/transform correction or invent source sorting.
- Workers own readers/caches and task spools; no shared mutable BAM/BW cursor. A bounded queue (default max_inflight=2*threads) returns task-ID keyed chunks; ordered assembly is independent of completion order. Semantic task sizes stay source-profile-bound; dynamic work stealing cannot alter grids/sampling/dedup ownership. Duplicate state resets exactly at defined source tasks/reference starts, including equal-position records at task boundaries.
- Memory is bounded by active tasks, indexed compressed blocks/zoom cache and output row blocks, not chromosome length per base. Matrix may spool row blocks for sorting/NPZ shape, with checked rows*columns byte sizes and a configurable private execution budget. Exact median/std paths may materialize one requested region/zone, never a whole chromosome implicitly. All temp, reopen/finish and worker errors bubble to main and nonzero exit; no `.ok()?` read suppression or production unwrap on input.

## 7. One integrated compatibility checker and fixed assertions

`tests/first_workflow.rs` owns one `whole_first_six()` entrypoint with named assertion groups, not many per-helper campaigns. It invokes the actual native binary on the accepted original/authored corpus, consumes the retained typed source exports and accepts a later qualified source-runtime comparison manifest. Missing executable/runtime/corpus is a failed required gate, never an early-return success. Lightweight unit tests may accompany algorithms naturally, but the acceptance ledger is one graph/checker.

**Lane A, frozen source correspondence:** reproduce filter and explicit sort/index prerequisite, CPM tracks, four BAM scaling profiles, BW compare/N-way average, BAM/BW bins+BED summaries and two-sample/two-group reference/scale/BED12/GTF matrices. Compare normal unaffected identities/values against actual retained exports. Source order is an identified multiset for summaries at threads>1; native order is stable by frozen TaskId then feature identity. Main matrix names are duplicate/duplicate_r1/late/reverse; reference 4x30, sample boundaries [0,15,30], scale 4x68 [0,34,68], both group [0,2,4]; BED12 2x20, GTF 2x48. Corrected zero/missing downstream populations are explicitly delta-classified rather than forced to the old source NaN masks.

**Lane B, connected native graph/same-file upstream:** every native-produced artifact is the actual next native input. Source comparisons read these same native intermediate BWs and typed matrix/NPZ exports; no old source BWs replace them. Keep both full/exact and default/zoom lanes. Test all source option classes with a compact meaningful selection, not just the 45 previous CLI invocations; add uncovered required mode assertions to this checker when implementation exposes them.

**Approved correction assertions (mathematical input contracts, not patched source answers):**

- Authored signed A/B at bin20: A [0–20=2,20–40=0,60–100=-2,100–131=0], B [0–20=-2,20–60=0,60–100=4,100–131=0]. Subtract plus skipZeroOverZero must emit 0–20=4 and 60–100=-6, with gaps for actual both-zero bins; not an empty file or just the final surviving run.
- Missing-as-zero subtraction additionally emits 20–60=0 and 100–131=0; skipNAs subtraction emits 20–40=0, leaves 40–60 absent and emits 100–131=0. Final short zero is 120–131 if fixed-step, merged into 100–131 otherwise. All-zero chr2 has explicit 0–333 interval in native derived output where zero-fill applies. Dictionary entry alone is insufficient.
- Merged signed log2 retains finite values before/after NaNs. Fixed-step ratio/pseudocount0 keeps four NaNs of seven bins; asymmetric log2 0,2 retains one +Inf/four -Inf/two NaNs including terminal 120–131. Do not 'fix' valid nonfinite arithmetic or signed header summaries to make goldens prettier.
- Filter BED+filtered-out succeeds, passed BED count remains 32 for the main A fragment case where paired geometry applies, and rejected BAM exactly contains original rejected records from filtering—not shifted copies or passed fragments. Metrics/report and both outputs publish together; injected rejected-output failure leaves previous destinations intact.

**Review focus / likely failures and their same-checker assertion owners:**

1. Task-edge/exon/repeated-block ownership: D/N/I/=/X/soft/hard clip, paired overlap, equal starts across tasks, mask-subrange grid restart and final partial bin; count_task and grid assertions.
2. Imported vs native-written zoom selection: retained 80/560/448 reductions, edge-weighted default/exact differences and source reading the same native BW; private stats/write assertions.
3. Multi-group orientation/identity: terminal #groups, duplicate names, GTF 1-based conversion, metagene exons, reverse sample blocks, unscaled ends, nanAfterEnd and sort subset; window/matrix assertions.
4. Invalid/corrupt/bounded input: bad BED12 counts, missing GTF transcript key, overflow/out-of-range BAM fields, truncated BW/NPZ write error and codec panic; contextual nonzero and no committed partial set.
5. Output collisions/late errors/thread nondeterminism: existing hardlink/symlink aliases, gzip/BAM/codec finish failure, threads 1/4/2 equality of native row identities and values, stable counters/factors; output/execute assertions.

**Numerical comparison policy, frozen before first native result:** categorical nonfinite masks/classes exact; identifiers/dimensions/boundaries/flags/CIGAR/tags/counters/scale populations exact. For source f64 reductions and factor exports, use abs 1e-12 + rel 1e-12, with matching reduction order where practical. General-format bedGraph compares normalized decimal numbers at the explicit six-significant-digit quantization stage, not one broad tolerance; source BW compares the resulting float32 values (at most one float32 ULP only where pre-quantization f64 accumulation can justify it). Matrix text compares source six-decimal cells with <=0.5e-6 plus the propagated decoded-input error. NPZ stays float64 and uses reduction bounds, not matrix-text tolerance. Default zoom comparisons on the same file use the f64 reduction bound; never a 5% blanket band. These stage bands are adopted before native outputs; diagnose failures rather than widening bands after the fact.

One initial integrated RED establishes missing whole workflow or named behavioral failures. Implement complete files, run the checker as a whole and preserve original RED/final logs. One whole-feature independent review covers API/production hot paths and contracts; one concentrated correction wave follows. No per-helper review/re-RED staircase.
